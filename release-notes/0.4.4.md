## Sturdier downloads and installs

- A mod or Script Extender download that drops picks up where it stopped instead of starting over.
- The Script Extender is checked against the checksum GitHub publishes before it is installed.
- A mod archive or save backup that would write outside its folder is refused, and a failed install or restore leaves nothing half-done.
- Saving a new Nexus API key updates the one in the Keychain instead of deleting it first.
- Signing the game for the Script Extender can no longer hang on codesign's output.
