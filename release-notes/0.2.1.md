## A clearer Script Extender log

- Each part of the Script Extender (Lua, Osiris, Stats…) has its own color in the log.
- On a game build the Script Extender wasn't made for, an orange **Limited mode** banner says which features are turned off. Warnings the Script Extender writes as ordinary lines now count as warnings.
- Mods the Script Extender lists by mistake (it sometimes matches a mod to another mod's scripts) are noted and no longer counted as Script Extender mods.
- Clicking a mod or part under **Problems** shows exactly its warnings and errors, with **Show All** to go back.
- Help covers the bar at the bottom, badges, mod details, and what to do when a Script Extender mod doesn't work.
