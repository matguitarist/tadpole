## Updates and the Script Extender

- **Updates**: a new page lists newer versions of your Nexus mods, with what changed. **Update** or **Update All** replaces the old file and keeps the mod's place in the load order. Tadpole checks at launch and every 6 hours, and notifies you.
- **Script Extender for macOS**: install [bg3se-macos](https://github.com/tdimino/bg3se-macos), an independent rebuild of Norbyte's Script Extender for Apple silicon, from Settings → Script Extender. Tadpole checks the download, keeps it up to date, and applies it again after game updates. It's unofficial, and each release is made for one game build: Tadpole tells you when yours isn't supported yet. Back up your saves first.
- **Script Extender Log** (⌘6): what the Script Extender loaded and what went wrong, with errors grouped by mod, updating while you play.
- **Collections** show which mods need the Script Extender before you install them, with an option to skip them.
- **Mod details** show the mod's picture from Nexus, its status, size, and every file on its Nexus page, main and optional. Mods installed from files can be linked to Nexus with **Find on Nexus…**.
- **Install All** for mods split into several files.
- **Menu bar icon** with the game's version, Play, mod updates and downloads. Turn it off in Settings → General.
- A bar at the bottom of the window shows the game's and the Script Extender's versions.
